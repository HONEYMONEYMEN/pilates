# Мой пилатес

Приложение для тренера по пилатесу: клиенты, пакеты, расписание, отметки посещений и заработок (50%).

- `index.html` — всё приложение
- `firebase-config.js` — настройки Firebase (данные хранятся в Firestore, у каждого пользователя свои)
- `sw.js`, `manifest.webmanifest`, иконки — чтобы ставилось на телефон/ПК как приложение и работало офлайн

Правила подсчёта: «Пришёл» и «Не предупредил» списывают занятие из пакета и дают 50% от цены занятия; «Отменил заранее» не списывает.
